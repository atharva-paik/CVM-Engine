CVM++ COMMAND AND SYNTAX GUIDE
==============================

This file contains the practical commands and language syntax for building,
running, debugging, and demonstrating the CVM++ compiler and stack-based VM.




1. COMPILE THE PROJECT AND GENERATE THE EXE FILE
------------------------------------------------

What it does:
Compiles src/main.cpp and all included header files into a Windows executable
named cvm.exe.

Command:
g++ -std=c++17 src/main.cpp -o cvm.exe


2. OPTIONAL STRICTER COMPILE COMMAND
------------------------------------

What it does:
Compiles the project with additional compiler warnings enabled. This is useful
when checking code quality.

Command:
g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -o cvm_new.exe


3. RUN A CVM SCRIPT NORMALLY
----------------------------

What it does:
Runs a .cvm script and prints only the final VM output.

Command:
.\cvm.exe tests\test_arithmetic.cvm


4. RUN A SCRIPT WITH FULL DEBUG OUTPUT
--------------------------------------

What it does:
Runs the complete compiler pipeline and prints:
1. AST
2. Bytecode
3. VM output

Command:
.\cvm.exe tests\test_arithmetic.cvm --debug

Short form:
.\cvm.exe tests\test_arithmetic.cvm -debug


5. PRINT ONLY THE AST
---------------------

What it does:
Parses the program and prints the generated Abstract Syntax Tree before
executing the VM.

Command:
.\cvm.exe tests\test_arithmetic.cvm --ast

Short form:
.\cvm.exe tests\test_arithmetic.cvm -ast


6. PRINT ONLY THE BYTECODE
--------------------------

What it does:
Compiles the AST and prints the generated bytecode instructions before
executing the VM.

Command:
.\cvm.exe tests\test_arithmetic.cvm --bytecode

Short form:
.\cvm.exe tests\test_arithmetic.cvm -bytecode


7. SET A CUSTOM VM STEP LIMIT
-----------------------------

What it does:
Limits how many bytecode instructions the VM can execute. This protects the
program from accidental infinite loops.

Command:
.\cvm.exe tests\test_truth_machine.cvm --max-steps 40

Short form:
.\cvm.exe tests\test_truth_machine.cvm -max-steps 40


8. START INTERACTIVE TERMINAL MODE
----------------------------------

What it does:
Starts CVM++ without a file. You can type one-line programs directly into the
terminal.

Command:
.\cvm.exe

Exit commands inside the terminal:
exit
quit

Important note:
Interactive mode evaluates each entered line as a separate program. Variables
do not persist across separate terminal prompts. Use a .cvm file for multi-line
programs.


9. RUN INPUT-BASED PROGRAMS
----------------------------

What it does:
Runs a program that contains the input keyword. The VM waits for an integer
from the user.

Command:
.\cvm.exe tests\test_input.cvm

Then type an integer, for example:
7


10. RUN INPUT-BASED PROGRAMS USING ECHO
---------------------------------------

What it does:
Passes input directly into the program without manually typing it.

Command:
echo 7 | .\cvm.exe tests\test_input.cvm

Expected behavior:
If test_input.cvm multiplies input by 10, input 7 prints 70.


11. RUN THE TRUTH MACHINE WITH INPUT 0
--------------------------------------

What it does:
Passes 0 into the truth machine. It should print 0 once and stop.

Command:
echo 0 | .\cvm.exe tests\test_truth_machine.cvm


12. RUN THE TRUTH MACHINE WITH INPUT 1 SAFELY
---------------------------------------------

What it does:
Passes 1 into the truth machine. A truth machine normally prints 1 forever, so
the VM step limit stops it safely.

Command:
echo 1 | .\cvm_new.exe tests\test_truth_machine.cvm --max-steps 40

Expected behavior:
The program prints a few 1 values and then stops with:
RUNTIME ERROR: Step limit exceeded. Possible infinite loop.


13. RUN THE DIVISION-BY-ZERO TEST
---------------------------------

What it does:
Runs a script that attempts division by zero. The VM catches the error and
prints a clean runtime message instead of crashing.

Command:
.\cvm.exe tests\test_div_zero.cvm

Expected behavior:
RUNTIME ERROR: Division by zero.


14. RUN ALL TEST FILES MANUALLY
-------------------------------

What it does:
Runs each major sample script one by one.

Commands:
.\cvm.exe tests\test_arithmetic.cvm
.\cvm.exe tests\test_booleans.cvm
.\cvm.exe tests\test_if_else.cvm
.\cvm.exe tests\test_fizzbuzz.cvm
echo 7 | .\cvm.exe tests\test_input.cvm
echo 0 | .\cvm.exe tests\test_truth_machine.cvm
.\cvm.exe tests\test_div_zero.cvm


15. RUN ALL NON-INPUT TESTS WITH DEBUG OUTPUT
---------------------------------------------

What it does:
Runs the tests that do not need user input and prints AST, bytecode, and VM
output for each one.

Commands:
.\cvm.exe tests\test_arithmetic.cvm --debug
.\cvm.exe tests\test_booleans.cvm --debug
.\cvm.exe tests\test_if_else.cvm --debug
.\cvm.exe tests\test_fizzbuzz.cvm --debug
.\cvm.exe tests\test_div_zero.cvm --debug



16. BASIC LANGUAGE SYNTAX
-------------------------

What it does:
Shows the syntax supported by the CVM++ language.

Variable declaration:
let x = 10;

Variable assignment:
x = x + 1;

Print output:
print x;

Take integer input:
input x;

17. INTEGER AND BOOLEAN SYNTAX
------------------------------

What it does:
Shows how integer and boolean values are written.

Integer values:
let a = 10;
let b = 0;
let c = -5;

Boolean values:
let t = true;
let f = false;

Important note:
Inside the VM, booleans are stored as integers:
true  = 1
false = 0


18. ARITHMETIC SYNTAX
---------------------

What it does:
Shows supported arithmetic operations.

Addition:
let sum = a + b;

Subtraction:
let diff = a - b;

Multiplication:
let mult = a * b;

Division:
let div = b / a;

Parentheses:
let complex = (a + 5) * 2;

Unary minus:
let neg = -a;
let value = x * -3;
let grouped = x * (-3);


19. COMPARISON SYNTAX
---------------------

What it does:
Shows supported comparison operations. Comparison results are 1 for true and
0 for false.

Equal:
let same = x == y;

Not equal:
let different = x != y;

Less than:
let small = x < y;

Greater than:
let big = x > y;

Less than or equal:
let le = x <= y;

Greater than or equal:
let ge = x >= y;


20. IF/ELSE SYNTAX
------------------

What it does:
Runs one branch if the condition is true, otherwise runs the else branch.

Syntax:
if (code == 1) {
    print 999;
} else {
    print 0;
}


21. WHILE LOOP SYNTAX
---------------------

What it does:
Repeats the body while the condition evaluates to true.

Syntax:
let count = 5;

while (count > 0) {
    print count;
    count = count - 1;
}


22. INPUT SYNTAX
----------------

What it does:
Reads one integer from standard input and stores it in a variable.

Syntax:
input userVal;
print userVal;

Command:
echo 12 | .\cvm_new.exe tests\test_input.cvm


23. OUTPUT SYNTAX
-----------------

What it does:
Prints the value of an expression.

Syntax:
print 10;
print x;
print x + 5;
print x == 5;


24. DEBUG OUTPUT MEANING
------------------------

What it does:
Explains what each debug section represents.

AST:
The tree structure generated by the parser.

Bytecode:
The linear instruction list generated by the compiler.

Program output:
The final values printed by the virtual machine.

Command:
.\cvm.exe tests\test_if_else.cvm --debug


25. WHAT EACH SOURCE FILE DOES
------------------------------

src\lexer.h:
Converts source code text into tokens.

src\Parser.h:
Converts tokens into an Abstract Syntax Tree using recursive descent parsing.

src\ast.h:
Defines AST node types and prints the AST in debug mode.

src\compiler.h:
Compiles AST nodes into custom bytecode instructions.

src\virtualmachine.h:
Executes bytecode using a stack and memory array.

src\main.cpp:
Handles command-line arguments, file execution, debug flags, and interactive
terminal mode.
